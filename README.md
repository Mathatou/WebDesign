# Saint-Gratien – Town web presentation

University project for the course **Web Design (ITW)**, FIT BUT, 2026/27.

## Team
- Ervenn Rannou
- Mathias Aubry
- Adrian Noguero

## How to open
Open `src/index.html` in a web browser. No server or build step is needed.

## Structure
- `src/` – HTML pages, `style.css` (shared stylesheet) and small JavaScript files
  (`sSight.js`, `sHistory.js` for the info dialogs, `sContact.js` for the contact form)
- `img/` – pictures used on the pages

All events and phone numbers on the website are fictional.
